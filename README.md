# LyricWave

Музыкальный плеер, в котором текст песни появляется строчка за строчкой в такт, а фоновая анимация подстраивается под мелодию: на спокойных местах успокаивается, на мощных — разгоняется.

**Открыть веб-версию:** https://rizobek.github.io/lyricwave/

- 6 анимаций и 6 стилей текста, цвета из обложки
- Добавление своих песен: ссылки YouTube, прямые ссылки на аудио, файлы с компьютера
- Тексты подтягиваются автоматически из открытой базы [LRCLIB](https://lrclib.net)
- Обмен плейлистами по ссылке

Версия для Windows (`LyricWave.exe`) умеет больше: ссылки почти с любого сайта, поиск по названию и анимацию, которая слышит настоящий звук.
